# Anvil 2.7.0 — Communication & Artifact Intelligence

Anvil 2.7.0 adds a model-agnostic, evidence-first workflow for analyzing explicitly authorized sources and materializing defensible Markdown reports, slide outlines, and architecture SVG. The capability is available with both supported OpenCode runtime adapters.

## Added

- Added the lazy `anvil-communication` skill and generic `/review` command while preserving natural language as the primary interface.
- Added a runtime-independent standard-library core for bounded input discovery/extraction, typed evidence and finding provenance, quantitative insight contracts, audience/constraint planning, Markdown materialization, architecture semantics/SVG, and deterministic review.
- Added deterministic decimal arithmetic for absolute and relative change, percentage points, normalization, distribution summaries, explicit exclusions, and qualified projections.
- Added arithmetic revalidation before materialization and provenance references for measured observations, findings, and diagram claims.
- Added local DOCX/PPTX/XLSX text/value extraction and optional PDF text extraction through `pdftotext`.
- Added a semantic architecture model and accessible SVG renderer that rejects node overlap, incomplete boundaries, and edges that cross unrelated nodes.
- Added communication capability visibility to `make capabilities` in text and JSON.

## Compatibility and limits

- OpenCode 1.x and 2.x remain supported; the communication helper does not use an OpenCode 2-only feature. No model is pinned, no agent or MCP server is added, and no persistent state schema changes.
- No Python package or external renderer is required. PDF text extraction is optional and detected locally.
- Markdown reports, Markdown slide outlines, and architecture SVG are supported outputs. Binary PPTX/DOCX/PDF, quantitative chart rendering, OCR, and dynamic animation remain unavailable and are reported explicitly.
- OOXML extraction reads bounded text/value subsets. Images, charts, notes, embedded objects, formulas requiring recalculation, and scanned PDF pages are not interpreted.
- Artifact analysis does not write to memory or the source registry. The helper does not initiate Databricks queries or mutations; existing explicit authorization and read-only query rules continue to apply.
- Deterministic PASS results cover contracts and checks only. They do not prove claim truth or narrative quality; semantic review remains pending until a person/model reviews the artifact and sources.

## Upgrade

Run `make test`, inspect the current Anvil state, then use `make upgrade` to install this Anvil release while preserving the exact validated OpenCode executable. This copies the new skill, `/review` command, helper, and standard-library modules into the managed config. No data migration or special reforge is required. `make update-runtime` remains an explicit same-major OpenCode operation and is not required for this feature.

Offline tests cover deterministic calculations, evidence references, exact five-slide structure, local input extraction, Markdown materialization/review, SVG layout, and OpenCode 1/2 config fixtures. The runtime fixture is not a live OpenCode service test. Network required: existing runtime provisioning, `make update-runtime`, `make migrate-runtime`, and explicitly requested Databricks setup retain their prior network behavior; Anvil artifact analysis itself is local.
