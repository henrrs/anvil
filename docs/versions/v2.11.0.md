# Anvil 2.11.0 — Analytical, Editorial & Visual Communication Intelligence

This candidate extends the schema-1 communication plan while keeping analysis, editorial selection, visual intent, Markdown/SVG materialization, and review separate. It runs with the existing OpenCode 1.x and 2.x support and adds no required dependency or persistent-data migration.

## What changed

- Evidence can use explicit `OBSERVED`, `CALCULATED`, `ESTIMATED`, `SCENARIO`, `INFERRED`, and `UNKNOWN` labels, alongside the legacy Anvil values. Scenario-derived metrics remain labeled in their displayed narrative.
- Findings can record counter-evidence, alternative explanations, materiality, implications, and qualifications. Editorial plan metadata carries decision context and explicit appendix selections.
- The audience contract now supports executive, financial, technical leadership, engineering, technical, and mixed readers. The raw decimal observations and recomputed quantitative values remain unchanged; displayed values can be compact and audience-aware.
- Sections and slides can express renderer-independent visual relationships, form, primary message, evidence focus, prominence, semantic color roles, and motion storyboards. Markdown retains motion states and reports the static renderer fallback.
- `python3 scripts/artifacts.py critique PLAN.json` reports bounded editorial and visual review signals. These are review targets; semantic truth, materiality, visual quality, and audience fit remain model/human judgments.
- SVG review checks measurable viewport geometry, and diagram planning rejects routes that leave the declared canvas. Existing overlap, containment, and edge-crossing checks remain.
- Five offline cases cover executive finance, architecture, Spark performance, request flow/motion, and an unrelated business example.

## Evaluation and known limits

The schema, arithmetic, audience transformations, appendix selection, storyboard fallback, CLI critic, and static SVG geometry checks are covered by deterministic tests. A prior Anvil-generated Markdown quantitative fixture was captured as a pre-change baseline and is compared in the [engineering report](../communication-intelligence-v2.11-report.md).

The repository contains no current Anvil PPTX or GIF presentation to render and review. Binary PPTX and dynamic-animation renderers were already unsupported, so this candidate preserves Markdown/SVG output and cannot demonstrate measurable improvement to the absent deck. No live model semantic evaluation or rasterized slide review was run. **Status: NOT RELEASE READY** until the actual Anvil presentation benchmark is supplied, rendered through its supported path, and reviewed before/after.

## Upgrade and compatibility

```bash
git pull origin master
make test
make upgrade DRY_RUN=1
make upgrade
make doctor
python3 scripts/artifacts.py critique PLAN.json
```

The Anvil-only upgrade preserves the exact validated OpenCode executable/version. OpenCode 1.x and 2.x remain supported. The schema-1 plan changes are additive; no runtime or persistent-data migration is required. The supported source-profile window now spans five prior minor releases and retains 2.6.x installs.

Network required: **NO** for `make upgrade`. `make update-runtime` and `make migrate-runtime OPENCODE_MAJOR=N` remain separate explicit runtime operations.
