# Anvil 2.7.1 — Installed Profile Compatibility

Anvil 2.7.1 fixes a lifecycle regression in Anvil 2.7.0. Existing OpenCode 1 and OpenCode 2 profiles installed by Anvil 2.6.x remain valid upgrade sources even though they do not yet allow the new `anvil-communication` skill.

## Fixed

- Lifecycle inspection, doctor, Anvil upgrade, runtime update/migration, and reforge use a backward-compatible audit for previously installed profiles.
- Compatible profile audits retain the security checks for runtime shape, default-deny skill access, protected shell commands, and known Anvil skills. Current-release candidate configs continue to require the full current skill set.
- Added end-to-end offline regressions that upgrade Anvil 2.6.1 profiles on OpenCode 1 and 2 and verify the communication skill is included after upgrade.

## Compatibility

- OpenCode 1.x and 2.x remain supported. No runtime upgrade, data migration, external package, or network access is required for `make upgrade`. Network required: NO for the Anvil upgrade.
- `make update-runtime` remains the explicit same-major OpenCode update; it is not needed to install this Anvil patch.
- `make upgrade` preserves the exact validated OpenCode executable/version, user data/state, and Anvil memory.
- Communication and Artifact Intelligence remains available as introduced in 2.7.0. Binary PPTX/DOCX/PDF rendering is unavailable.

Run `make inspect`, then `make upgrade DRY_RUN=1` and `make upgrade` from the updated Anvil checkout. The upgrade adds the 2.7.1 skill and `/review` command while preserving the existing runtime.
