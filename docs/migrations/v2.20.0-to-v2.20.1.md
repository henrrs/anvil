# Anvil 2.20.0 to 2.20.1

This patch clarifies the existing lazy `anvil-engineering` skill trigger for explicit dependent phases and hardens the Anvil-only upgrade rehearsal. It does not change task-state data, runtime requirements, provider configuration, authentication, or OpenCode major support.

Inspect the current installation and review the generated plan before applying it:

```bash
make inspect
make upgrade DRY_RUN=1
make upgrade
make test
```

The upgrade replaces only Anvil-owned managed artifacts after snapshotting the current state. It preserves the exact validated OpenCode executable and user-owned configuration. The preflight stats smoke uses empty temporary XDG directories and does not copy the user's OpenCode database, credentials, runtime state, or Anvil memory. No task-state migration or runtime installation is needed. `make reforge` can also regenerate the Anvil-managed profile from the current repository release.
