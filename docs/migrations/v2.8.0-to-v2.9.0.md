# Anvil 2.8.0 to 2.9.0

This additive release installs lazy engineering/system-design skills, deeper Spark references and the local `engineering.py` package. Existing Anvil memory, Databricks configuration, communication artifacts and public Make commands retain their behavior. No engineering-state file is required to use Anvil.

```bash
git pull origin master
make test
make upgrade DRY_RUN=1
make upgrade
make doctor
make capabilities
```

The source-to-target plan preserves unowned files and lists a bounded sample with exact counts. New owned-path collisions block before mutation. Existing supported profiles are audited against their source release; missing new skills do not imply corruption. The 2.9 source window includes the current plus three prior minors, retaining 2.6.x compatibility. Existing managed manifests, verified snapshots and interruption recovery remain in force.

Anvil upgrade preserves the exact validated OpenCode executable and version. Network required NO. `make update-runtime` and `make migrate-runtime OPENCODE_MAJOR=N` remain separate explicit choices. No OpenCode runtime migration, provider authentication or model call is needed for this release.

Long-task state is created only for justified/explicit tasks under `${XDG_STATE_HOME:-$HOME/.local/state}/anvil/engineering/`. Upgrade, reforge and rollback do not delete or rewrite it. This is separate from durable memory. A rollback to an older helper may not understand a newer task schema; keep the JSON and reinstall a compatible helper rather than editing verification into it. Current schema version is 1. Absent state remains valid.

After compaction/interruption, ask Anvil to resume the repository/task ID. `WORK_STATE_STALE` requires focused revalidation/replanning; changed specifications need semantic normalization. A `WORK_STATE_CORRUPTED` task is left unchanged and can be explicitly recovered from the previous inspected generation with all verification invalidated. These errors do not classify the Anvil installation as corrupted. See [engineering usage](../engineering.md).
