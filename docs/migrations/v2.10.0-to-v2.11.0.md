# Anvil 2.10.0 to 2.11.0

Anvil 2.11 extends the communication artifact contract additively. There is no OpenCode runtime, config, Databricks, task-state, memory, or other persistent user-data migration.

No runtime or persistent-data migration is required.

```bash
git pull origin master
make test
make upgrade DRY_RUN=1
make upgrade
make doctor
python3 scripts/artifacts.py critique PLAN.json
```

Existing communication plans remain schema version 1. New plans may add epistemic labels, finding materiality/counter-evidence, editorial appendix selections, audience-specific presentation policies, semantic `visual_intent`, and motion storyboards. Existing Markdown and SVG outputs remain supported. A storyboard is preserved as text when a dynamic renderer is unavailable.

`SCENARIO` values remain visibly distinct from observed measurements in quantitative narratives.

The source-profile migration window increases to five prior Anvil minor releases so 2.6.x profiles remain supported in this release. OpenCode 1 and 2 remain supported; `make upgrade` does not update OpenCode. Rollback behavior and user data formats are unchanged.

See the [2.11 release notes](../versions/v2.11.0.md) and [communication engineering report](../communication-intelligence-v2.11-report.md) for capability boundaries and the pending actual-deck regression gate.
