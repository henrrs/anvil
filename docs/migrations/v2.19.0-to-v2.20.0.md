# Anvil 2.19.0 to 2.20.0

This release adds optional engineering continuity at native OpenCode 2 compaction and engineering evaluation/guidance. It does not change persistent schemas, managed runtime requirements, provider configuration, authentication, or OpenCode-major support.

The supported same-major Anvil migration source window expands by one minor release and continues to include installations on Anvil 2.6.x.

```bash
make inspect
make upgrade DRY_RUN=1
make upgrade
make test
make eval-engineering
```

The upgrade is local and preserves the exact validated OpenCode runtime. Existing task state and Markdown memory are preserved as before. There is no explicit migration command.

OpenCode 2 may add a bounded checkpoint during native compaction when exactly one active Anvil task belongs to the session repository and the installed plugin API exposes the documented hook. OpenCode 1 has no Anvil compaction hook; continue to call `engineering.py resume` explicitly. Lack of hook support is non-fatal and does not change native compaction behavior.
