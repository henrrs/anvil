# Anvil 2.14.0 to 2.15.0

## Summary

This MINOR update adds an evidence-backed semantic context and a deterministic semantic certification target. It changes no persistent state, OpenCode runtime, profile ownership, or Databricks configuration. No manual migration is required.

## Upgrade

Review and apply the ordinary Anvil-only upgrade:

```bash
make inspect
make upgrade DRY_RUN=1
make upgrade
make doctor
make test
```

`make upgrade` preserves the installed OpenCode version and major. Use `make update-runtime` or `make migrate-runtime` only for a separately intended OpenCode runtime operation. **Network required:** no for the Anvil upgrade.

## Semantic profiles

The analysis helper now emits additive semantic context schema v2. Existing schema-v1 contexts remain accepted. Profiles are task-local; regenerate with `python3 scripts/analyze.py profile named-data.csv` when you want new evidence. Optional `--semantic-metadata metadata.json` accepts schema-v1 field roles, entity/event key groups, unique constraints and observation grain. It is not required for ordinary use.

The semantic change distinguishes observation count, persistent entities/entity keys, events/event keys, technical row keys, dimensions, temporal roles, measures, candidate keys and observation grain. Uniqueness and `_id` names are evidence only. Claims about entity counts must use the supported entity key fields and respect confidence/abstention.

## Verify semantic certification

```bash
make eval-analytical
make eval-analytical-semantic
```

The second command checks the versioned A–X adversarial suite and records candidate results separately from the immutable 2.14 baseline. Its `READY_FOR_MODEL_EVALUATION` outcome means deterministic semantic gates passed; it does not claim model quality or release readiness.
