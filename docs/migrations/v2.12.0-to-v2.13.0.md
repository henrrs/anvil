# Anvil 2.12.0 to 2.13.0

Anvil 2.13 adds local intent contracts and bounded analytical profiling/operations. It extends the existing lazy `anvil-communication` skill, so no agent, OpenCode profile permission, provider, model, runtime major, memory schema, Databricks setting, or Make target is added. The same helper works on supported OpenCode 1.x and 2.x installations.

Preview and install Anvil while preserving the exact OpenCode runtime and existing user/local configuration:

```bash
git pull origin master
make test
make upgrade DRY_RUN=1
make upgrade
make capabilities
```

The upgrade installs the managed `scripts/analyze.py` helper and `scripts/analysis/` package through the existing ownership manifest, verified snapshot, staging, and rollback transaction. It does not change user-owned config, OpenCode data/state, Databricks providers, or Anvil memory. The supported automatic same-major source window now spans seven prior minor releases, retaining the supported 2.6.x source line.

The installed helper is `${XDG_CONFIG_HOME:-$HOME/.config}/opencode/scripts/analyze.py`. For example:

```bash
python3 "${XDG_CONFIG_HOME:-$HOME/.config}/opencode/scripts/analyze.py" profile ./named-data.csv
```

See the [analytical-intelligence guide](../analytical-intelligence.md) for supported formats, execution budgets, the source-hash-bound plan format, evidence types, and current evaluation limits. The 2.13.0 candidate remains **NOT RELEASE READY** until live-model semantic/claim-quality, token/latency, and real-task evaluation become available; offline tests do not establish those properties.
